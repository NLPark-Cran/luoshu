⚙️ 设置 · 设备登记（反向隧道）

登记后洛书会主动连接云端（wss），云端 Agent 即可调用本机工具。 设备凭证只保存在 ~/.luoshu/device.json（0600）。

如何获取设备凭证？

在下方「云端地址」登录账号后，创建设备（token 只显示一次）： 

curl -X POST <云端地址>/api/v2/devices \
  -H "Authorization: Bearer <你的登录 JWT>" \
  -H "Content-Type: application/json" \
  -d '{"name": "我的机器"}'
